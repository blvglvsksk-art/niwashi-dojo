# 庭師道場

造園技能士（3級〜1級）・造園施工管理技士（2級・1級）の稽古アプリ。

- アプリ：https://blvglvsksk-art.github.io/niwashi-dojo/
- プライバシーポリシー：https://blvglvsksk-art.github.io/niwashi-dojo/privacy.html

iPhone は Safari で開いて「共有 → ホーム画面に追加」。一度開けばネットがなくても使えます。
